# Privacy

This plugin runs inside the FastGPT Plugin service. It sends the chosen search query, filters, and application API key over HTTPS to api.acedata.cloud. It has no separate telemetry endpoint or persistent storage.

FastGPT stores the key through its plugin secret configuration. Do not put keys in workflow inputs, exports, screenshots, or support requests. Request records follow the [Ace Data Cloud privacy terms](https://platform.acedata.cloud/privacy). The FastGPT administrator controls plugin installation and credential access.
